📊 Pipeline Flow (Phases 0–9)

  1. Phase 0–1: Numerics, weather, site location
  2. Phase 2: Physical constants (registry)
  3. Phase 3: PVT electrical/thermal specs, curves, soiling
  4. Phase 4: Tank geometry, heating cycle
  5. Phase 5: Solar loop hydraulics
  6. Phase 6: Treatment pathways, removal coefficients
  7. Phase 7: Electrical system, controllers, sensors
  8. Phase 8: Output interval
  9. Phase 9: Economics, tariffs, scenarios
