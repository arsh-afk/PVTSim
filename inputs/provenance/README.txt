Store source documents and descriptions for datasheets, test reports, papers,
lab reports, and weather data here. Reference each source from the matching
parameter or table `source_ref`; keep references accurate if files move or are
renamed. Demo-default assumptions are listed separately in
`demo_defaults.yaml` and are not measured or calibrated evidence. See the
project [README](../../README.md) and [data entry guide](../../DATA_ENTRY_GUIDE.md).
