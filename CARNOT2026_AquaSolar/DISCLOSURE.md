# Prior Work Disclosure

This project builds on AquaSolar Living, a research concept developed at the American University of Ras Al Khaimah under the CMAT-00184 Theme 5 initiative. The current Carnot 2026 package is a restructured, competition-oriented submission that consolidates the model documentation, runnable simulation code, provenance files, and supporting references.

## New Work for Carnot 2026
- Consolidated mathematical formulation from the PVT, tank, and treatment-pathway logic into a competition-ready report
- Structured equation and assumption registries in a reusable `model/` package
- Reproducible simulation bundle with parameter, weather, and results provenance
- Clear emphasis on assumptions, scope limits, and live-defence readability
- Added package-level documentation for submission readiness and reproducibility
