Convert weather data and required fields

From the project folder, run python -m aquasolar.io.weather_converter --format epw source.epw inputs/timeseries/weather-new.csv --calendar-year 2025 --site-timezone Asia/Dubai. Use tm2 for TRNSYS TMY2/TM2 files or nasa-power for NASA POWER hourly JSON. TM2 and EPW need --calendar-year; all formats need the modeled site's IANA --site-timezone. The converter creates a CSV and matching .meta.yaml; choose unique filenames and upload both below.

Required CSV headers and units: timestamp (ISO 8601 with explicit UTC offset), ghi, dni, and dhi (W/m²), t_ambient (°C), and wind_speed (m/s). Use hourly, chronological records with numeric values in every required field. Optional headers are poa_irradiance (W/m²), relative_humidity (%), cloud_cover (use the source's documented unit), and qc_flag.
